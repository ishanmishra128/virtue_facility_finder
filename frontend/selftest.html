Virtue Foundation Frontend self-tests (simulated browser checks)

These checks run the served app in an iframe on this page and confirm basic wiring: quick-search chips, a live search request, result cards with evidence, the comparison flow, the interactive facility map (including a live basemap-tile load check), and the evidence drawer. They use only the public app UI — no internals, no secrets. Run them while signed in to Databricks.
